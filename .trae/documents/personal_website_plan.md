# 个人技术展示网页 - 技术文档

## 📋 项目概述

为汪民胜创建一个**极简科技风**的个人技术展示网页，以网页为主展示平台，通过一个链接让面试官快速了解技术能力和项目经验。

## 🎯 设计风格

- **主题**: 深色科技风（深蓝/黑色背景）
- **配色**: 主色调 #0f172a，点缀色 #3b82f6（蓝色）、#10b981（绿色）、#f59e0b（橙色）
- **风格**: 简洁、现代、专业，突出技术含量

## 📐 网页结构

### 1. Header 导航头部
- 固定导航栏，滚动时背景渐变
- 个人姓名和待业时间显示（可切换显示/隐藏）
- 页面加载时间显示（LCP）
- 快速导航链接

### 2. Hero 区域
- 动态粒子背景效果
- 个人姓名和一句话定位
- 技术标签云展示
- 快速导航按钮（向下滚动）

### 3. 技术栈可视化
- 雷达图展示核心技术能力
- 技术分类：前端、后端、运维、工具
- 掌握程度区分：精通/熟练/熟悉
- 鼠标悬停显示技术解释
- 动态加载动画

### 4. 项目展示
- 卡片式布局展示核心项目
- 项目信息：名称、技术栈、描述、亮点
- B 站视频链接跳转
- 悬停效果展示更多细节

### 5. 工作经历时间线
- 按年份展示工作经历
- 突出关键项目和成就
- 公司名称和职位
- 时间线动画效果

### 6. 视频演示区域
- B 站外链视频列表
- 项目视频封面图
- 支持手机端播放

### 7. 联系方式
- 邮箱、电话、所在地
- 微信二维码弹窗
- 互助群二维码弹窗
- 简历预览与下载
- GitHub、博客链接

## ✨ 核心功能实现

### 1. 待业时间计算
- 基于 `leaveDate` 计算当前日期与离职日期的天数差
- 结果缓存到 LocalStorage，每日零点更新
- 支持显示/隐藏切换

### 2. 技术栈悬停提示
- 鼠标悬停技术名称时显示一句话解释
- 使用 framer-motion 实现平滑动画
- 解释文案存储在 techStack.ts 中

### 3. 简历预览与下载
- 单击：在浏览器中打开 PDF
- 点击下载按钮：下载到本地

### 4. 二维码弹窗
- 微信二维码和互助群二维码
- 使用 framer-motion 实现弹窗动画
- 点击遮罩关闭

### 5. 页面加载时间
- 使用 PerformanceObserver 监控 LCP
- 在 Header 中显示加载耗时
- 单位为毫秒

### 6. 图片优化
- 使用脚本将关键图片转为 Base64 编码
- 减少 HTTP 请求，提升加载速度
- 更新图片后需重新运行 `npm run images`

## ⚠️ 风险与注意事项

1. **版本兼容性**: Tailwind CSS v3 使用 PostCSS 配置，不要使用 `@tailwindcss/vite` 插件（该插件专为 v4 设计）
2. **页面加载速度**: 图片已转为 Base64，避免添加过大资源
3. **响应式设计**: 确保在移动端和 PC 端都有良好的显示效果
4. **视频资源**: 使用 B 站外链，避免本地视频文件
5. **隐私保护**: 避免在网页上展示敏感信息
6. **部署更新**: 使用 `npm run deploy` 而非手动操作 gh-pages 分支
